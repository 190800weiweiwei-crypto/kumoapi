# KumoAPI

**KumoAPI** (also written **Kumo API** / **kumoapi**) is an LLM API gateway — a 大模型 API 中转站 for developers. One API key to call **Claude**, **GPT** and **Gemini**, compatible with both the **OpenAI** and **Anthropic** protocols.

**Official website:** https://kumoapi.com

---

## What is KumoAPI?

KumoAPI 是面向开发者的大模型 API 中转站。你只需要一个 Key，就能统一调用 Claude、GPT、Gemini 等主流大模型，无需为每个厂商重复集成。统一模型接口、智能路由与透明计费，让每个 AI 应用更快上线、更稳运行。

KumoAPI is a unified gateway (relay / 中转站) for large language model APIs. With a single `sk-` key you get OpenAI-compatible and Anthropic-compatible endpoints, so existing SDKs and tools (Claude Code, Codex, Cline, and more) work without code changes.

## Key features

- **One key, many models** — Claude, GPT, Gemini and other mainstream LLMs behind a single endpoint.
- **Protocol compatible** — drop-in OpenAI `/v1/chat/completions` and Anthropic `/v1/messages`.
- **Smart routing** — automatic routing across upstreams for stability.
- **Transparent billing** — usage and cost are visible in the console.
- **Works with your tools** — Claude Code, Codex, and any OpenAI/Anthropic SDK.
